== Core Principles Review

=== Build vs Runtime Philosophy

The design goal of image mode is to push as much as possible to build time:

* **Build time** - Centralized, version-controlled, tested
* **Runtime** - Local customization, troubleshooting, instance-specific config

However, runtime flexibility is still available when needed:

* Local /etc configuration for instance-specific settings
* Rollback capabilities for quick recovery
* Switch operations for repurposing infrastructure

=== Recovery Capabilities

Image mode systems have built-in recovery options:

* **Rollback** - Revert to the previous deployment
* **Switch** - Change to a different image entirely
* **Staged updates** - Test updates before committing

These capabilities make it safer to experiment and faster to recover from issues.
