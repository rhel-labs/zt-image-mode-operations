= Image Mode Runtime Operations

Welcome to the Runtime Operations lab for RHEL Image Mode! This lab focuses on operational flexibility and troubleshooting techniques for image mode systems.

3. **Use switch and rollback** - Change system images and recover from issues

== Key Concepts

=== Build Time vs Runtime

Image mode encourages centralizing configuration at build time, but runtime flexibility is still needed for:

* **Troubleshooting** - Installing diagnostic tools temporarily
* **Testing** - Trying configuration changes before committing to an image
* **Recovery** - Rolling back to known-good states

=== Understanding the Filesystem

Image mode systems have a unique filesystem layout:

* **/usr** - Image state (read-only, replaced on update)
* **/etc** - Local configuration (merged with image, preserved on update)
* **/var** - Local state (never replaced, preserved across all operations)

Understanding these differences is critical for troubleshooting.
